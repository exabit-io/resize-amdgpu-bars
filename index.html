resize-amdgpu-bars apt repository

Signed Debian packages for resize-amdgpu-bars, Resizable BAR for AMD GPUs behind PCIe switches. Published by Exabit, Inc. from the project's GitHub releases.

sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://exabit-io.github.io/resize-amdgpu-bars/keys/resize-amdgpu-bars.gpg \
    | sudo tee /etc/apt/keyrings/resize-amdgpu-bars.gpg > /dev/null
echo 'deb [signed-by=/etc/apt/keyrings/resize-amdgpu-bars.gpg] https://exabit-io.github.io/resize-amdgpu-bars stable main' \
    | sudo tee /etc/apt/sources.list.d/resize-amdgpu-bars.list
sudo apt update
sudo apt install resize-amdgpu-bars

Signing key: Exabit, Inc. apt repository <packages@exabit.io>, fingerprint 6043 AD7B 3533 F615 C15F 48D0 4723 1665 0F4B E230 (ASCII-armoured, binary). Suite stable, component main; the package is architecture-independent.

Kernel packages (Ubuntu 24.04 HWE, Mac Pro 7,1 channel)

Ubuntu's linux-hwe-7.0 kernel rebuilt with the PCI bridge-window sizing fix that the 7.0 series needs for dual-die cards, as drop-in +barfix1 packages (same ABI and package names). Every rebuilt ABI goes into one rolling release, kernel-barfix, which is a signed flat apt repository (the linux-modules package is larger than GitHub Pages allows), signed with the same key as this site. Point apt at it once; new ABIs arrive with apt update && apt upgrade.

From 7.0.0-34 on, these kernels are built for the Mac Pro 7,1's Cascade Lake CPUs (-march=native). Do not subscribe other machines; see the release notes. The generic 7.0.0-31 build stays available as the kernel-7.0.0-31.31-24.04.1-barfix1 release.

echo 'deb [signed-by=/etc/apt/keyrings/resize-amdgpu-bars.gpg] https://github.com/exabit-io/resize-amdgpu-bars/releases/download/kernel-barfix ./' \
    | sudo tee /etc/apt/sources.list.d/linux-hwe-7.0-barfix.list
printf 'Package: *\nPin: release l=linux-hwe-7.0-barfix\nPin-Priority: 1001\n' \
    | sudo tee /etc/apt/preferences.d/linux-hwe-7.0-barfix
sudo apt update
sudo apt install linux-generic-hwe-24.04     # later: sudo apt update && sudo apt upgrade

Current: 7.0.0-34.34~24.04.1+barfix1 (ABI 7.0.0-34, Cascade Lake build); the channel also carries 7.0.0-31.31~24.04.1+barfix1. Not Secure Boot signed; see the release notes.
